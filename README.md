# Financial-Inventory-Management-System
A Financial and Inventory Manangment System for managing sales, purchases, expenses, inventory, receivables and payables, with SQL-based data management, Python implementation and Power BI dashboards for financial analysis and reporting.

# Financial and Inventory Management System

## Overview
A DBMS-based financial and inventory management project developed using Python, SQL and Power BI.

## Features
- Customer and supplier management
- Sales and purchase management
- Inventory management
- Expense management
- Receivables and payables
- GST calculation
- Cash book
- Bank reconciliation
- Profit and loss calculation
- Financial dashboard
- Inventory dashboard

## Technologies
- Python
- SQL
- Power BI
- Excel/CSV

## Project Status
Completed as a Minor Project with working modules, database structure and Power BI dashboards.
