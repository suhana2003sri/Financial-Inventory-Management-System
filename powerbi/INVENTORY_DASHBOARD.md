# Inventory Dashboard

The Inventory Dashboard will provide an overview of stock levels and inventory performance.

## Key Metrics
- Total Products
- Total Quantity in Stock
- Total Inventory Value
- Low Stock Products
- Purchase Quantity
- Sales Quantity

## Planned Visualizations
- Product-wise Stock
- Product-wise Sales Quantity
- Product-wise Purchase Quantity
- Low Stock Analysis
- Inventory Value Analysis

The dashboard will be developed using Power BI using data generated from the project database.
