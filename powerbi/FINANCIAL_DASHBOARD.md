# Financial Dashboard

The Financial Dashboard will provide an overview of the organization's financial performance.

## Key Metrics
- Total Revenue
- Total Expenses
- Gross Profit
- Net Profit
- Accounts Receivable
- Accounts Payable

## Planned Visualizations
- Monthly Revenue Trend
- Revenue vs Expenses
- Profit Analysis
- Receivables and Payables
- Expense Breakdown

The dashboard will be developed using Power BI with data generated from the project database.
