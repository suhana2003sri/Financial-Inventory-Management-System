# Project Documentation

## Project Name
Financial and Inventory Management System

## Objective
The project is designed to manage financial and inventory-related information and provide useful reports and visual analysis.

## Technologies Used
- Python
- SQL
- Power BI
- Excel/CSV

## Main Modules
- Customer Management
- Supplier Management
- Inventory Management
- Sales Management
- Purchase Management
- Expense Management
- Receivables and Payables
- GST Calculation
- Cash Book
- Bank Reconciliation
- Profit and Loss Calculation

## Dashboards
- Financial Dashboard
- Inventory Dashboard

## Project Outcome
The system provides a structured approach to managing financial and inventory data and presents important information through reports and Power BI dashboards.
